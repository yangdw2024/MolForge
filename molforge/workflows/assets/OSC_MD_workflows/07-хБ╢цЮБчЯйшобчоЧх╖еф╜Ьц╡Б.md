# 07 · 偶极矩 / 多极矩计算工作流（Multiwfn）

> 数据目录：`oujiju\`、`数据\6-311-偶极矩test\`
> 软件：Gaussian 16（生成波函数）+ Multiwfn 3.8（模糊原子空间分析）
> 方法：Hirshfeld* 划分 → 原子/分子多极矩

---

## 一、目的

计算分子对（D-A1 / A1-A2）中各组分的**偶极矩 μ** 与**多极矩**，用于：
- 分析分子间静电相互作用与堆积取向（偶极矩大小/方向）；
- 比较不同 BTn 受体端基卤素位置对电荷分布各向异性的影响；
- 为 ESP / 界面静电解释提供依据。

---

## 二、目录结构

| 子目录 | 分析对象 |
|--------|----------|
| `A1-A2/`（含 jieguo/md0~md4） | HDO 与 BTn 的受体对 |
| `D-A2/` | PM6 与 BTn 的给体-受体2 对 |

---

## 三、工作流步骤

### 3.1 步骤1：Gaussian 单点 + 波函数文件

对分子对做单点计算，得到 `.fchk` / `.wfn` 波函数文件。
（`数据\6-311-偶极矩test\` 用更大的 6-311G 基组做**基组收敛性测试**，泛函 B3LYP em=gd3bj。）

### 3.2 步骤2：Multiwfn 批量分析

`分子偶极矩.sh` 脚本对目录下所有 `.fchk` 循环执行：

```bash
for inf in *.fchk; do
    base_name=$(basename "$inf" .fchk)
    Multiwfn "$inf" -silent << EOF > "${base_name}_output.txt"
15        # 主功能 15：模糊原子空间分析
-1        # 反选
3         # Hirshfeld* 划分
-5
1-199     # 原子范围
2         # 功能 2：计算原子/分子多极矩
2
EOF
    mv multipole.txt "${base_name}_multipole.txt"
    cat "$output_file" >> all_outputs.txt
done
```

### 3.3 步骤3：结果整理

| 输出 | 内容 |
|------|------|
| `*_multipole.txt` | 分子多极矩（含各阶多极展开） |
| `*_atom_moment.txt` | 所有原子的偶极矩、四极矩张量本征值/本征向量 |
| `*_output.txt` | Multiwfn 完整交互日志（可追溯） |

---

## 四、解读要点

1. **偶极矩大小**：分子整体电荷分布不对称性；受体端基 F/Cl 转位改变 IC 端基偶极方向；
2. **半偶极矩（片段偶极）**：IC 端基片段的偶极矩用于判断端基对分子间静电识别的贡献；
3. 偶极矩差异 → 静电相互作用差异 → D-A 堆积与界面形貌差异；
4. `6-311-偶极矩test` 验证结果对基组不敏感，说明 6-31G* 级别偶极矩已收敛。
