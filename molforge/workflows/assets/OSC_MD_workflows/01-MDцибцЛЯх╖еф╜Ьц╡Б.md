# 01 · GROMACS 分子动力学模拟工作流

> 数据目录：`MD-1-BT1-FCLCLF` ~ `MD-4-BT4-FFCLCL`、`md70ns`
> 软件：GROMACS 2018.4（集群版 `gmx_mpi`），作业调度 SGE
> 前置：分子建模与力场参数化（见 00 文档）

---

## 一、模拟流程总览

每个三元体系（md1~md4）的文件夹结构即模拟步骤的顺序：

```
MD-n-BTn-XXXXXX/
├── 1-em/      能量最小化
├── 2-npt/     NPT 预平衡
├── 3-npt_1/   溶剂蒸发（循环删 CF + 二次平衡）
├── 4-MD80/    80 ns 形貌演化 MD
├── 5-DIO/     DIO 添加剂处理（去除后平衡）
├── 6-TA/      热退火（300→373→300 K）
└── modules/   各组分力场参数（*.itp, complex.top）
```

最终 70 ns 生产轨迹/结构统一存放在 `md70ns/`（`whole0~4.gro`、`rmsd0~4.xvg`）。

```
1-em → 2-npt → 3-npt_1(溶剂蒸发) → 4-MD80(去DIO) → 5-DIO → 6-TA(退火) → 70ns生产
```

## 二、各步骤详细参数

### 2.1 第一步：能量最小化（`1-em/`）

| 项目 | 参数 |
|------|------|
| 输入 | `PM6-HDO-BT1.pdb` |
| 算法 | 最陡下降法 steep |
| 收敛阈值 | emtol = 100.0 kJ/mol/nm |
| 步长 | emstep = 0.01 nm |
| 最大步数 | 50000 |
| 非键 | rcoulomb = rvdw = 1.0 nm，PME |
| 输出 | `minim.gro`、`potential.xvg` |

目的：消除初始构型原子重叠，得到无应力的起始结构。

### 2.2 第二步：NPT 预平衡（`2-npt/`）

| 项目 | 参数 |
|------|------|
| 系综 | NPT |
| 温度耦合 | V-rescale，ref_t = 300 K，tau_t = 0.5 ps |
| 压力耦合 | **Berendsen**，各向同性，ref_p = 1.0 bar，tau_p = 0.5 ps |
| 压缩率 | 4.5e-5 bar⁻¹ |
| 时长 | 1 ns |
| 输出 | `npt.gro`、`pressure.xvg`、`temperature.xvg` |

> 注意：2-npt 用 Berendsen（预平衡常用），4-MD80 / 6-TA 才用 Parrinello-Rahman。文献写作时不要混淆。

### 2.3 第三步：溶剂蒸发 + 二次平衡（`3-npt_1/`）

**核心脚本**：`npt_1.sge`（SGE 提交）+ `delete_solvent.py`（JAMIP 工具箱，作者 Jiahao Xie/JLU）

**循环逻辑**（`npt_1.sge` 内 `while (($loop<100))`）：

```
for loop in 1..100:
    1. cp npt.gro npt.gro_$loop          # 备份当前结构
    2. gmx make_ndx                       # 生成索引 index_com.ndx
    3. gmx grompp -f npt_1.mdp -c npt.gro -r npt.gro -p complex.top
    4. gmx mdrun -deffnm npt_1            # 100 ps NPT 短平衡
    5. mv npt_1.gro npt_input.gro
    6. python3 delete_solvent.py          # 随机删除 200 个 CF 分子
       → 更新 npt.gro 与 complex.top 中 CF 分子数
```

**`delete_solvent.py` 要点**：
- 从 `.gro` 中识别溶剂残基名（本体系 `CF`），按分子为单位**随机抽样删除**指定数量（默认 200）；
- 删除后自动重排剩余原子的原子序号与分子序号；
- 同步修改 `complex.top` 中 CF 的分子数（`change_complex_top`，行号 55）；
- 支持 `.gro` / `.pdb` 两种输入格式。

**设计意图**：先在氯仿中充分平衡使功能分子均匀混合，再逐步蒸发溶剂模拟"溶液成膜"过程，
避免直接真空模拟导致的功能分子结构冻结/非平衡堆积。论文描述为"500 个蒸发循环、每循环 100 ps 去除 100 个 CF"，
实际脚本为每循环 100 ps、删除 200 个 CF、上限 100 循环，两者口径不同，写作时以实际脚本为准。

### 2.4 第四步：80 ns 形貌演化 MD（`4-MD80/`）

| 项目 | 参数 |
|------|------|
| 积分器 | md（leap-frog），dt = 0.001 ps（1 fs） |
| 总步数 | 80,000,000 = **80 ns** |
| 温度 | V-rescale，300 K，tau_t = 0.5 ps |
| 压力 | Parrinello-Rahman，各向同性，1 bar，tau_p = 0.5 ps |
| 约束 | LINCS（H 键） |
| 静电 | PME，fourierspacing = 0.16，pme_order = 4 |
| 非键 | rlist = rcoulomb = rvdw = 1.0 nm |
| 输出 | nstxout-compressed = 2000（每 2 ps 一帧）、nstenergy = 2000 |
| 产物 | `md_whole.gro`、`rmsd1.xvg` |

目的：在（含 DIO）条件下长时间演化，使给/受体发生相分离并逐步排出 DIO。

### 2.5 第五步：DIO 添加剂处理（`5-DIO/`）

- 目录内仅保留 `npt.gro`：DIO 处理（去除添加剂后）的平衡结构。
- 该步骤对应论文中"80 ns MD 以促进 DIO 去除"后的再平衡。
- 后续以该结构进入热退火。

### 2.6 第六步：热退火 TA（`6-TA/`）

| 项目 | 参数 |
|------|------|
| 总时长 | 1,100,000 步 = 1.1 ns |
| 退火程序 | 12 个控制点：0→100→…→1000→1100 ps；300→373→…→373→300 K |
| 温度耦合 | V-rescale，tau_t = 0.2 ps（更紧） |
| 压力 | Parrinello-Rahman，1 bar |
| 产物 | `ply-md.gro`、`temperature.xvg` |

目的：模拟器件加工中的热退火后处理，高温促进分子重排与结晶，优化相分离形貌。

### 2.7 第七步：70 ns 生产 MD（`md70ns/`）

| 文件 | 内容 |
|------|------|
| `whole0.gro` ~ `whole4.gro` | md0~md4 最终结构（PBC 修复，whole） |
| `rmsd0.xvg` ~ `rmsd4.xvg` | RMSD 时间序列 |
| `rmsd*.png` | RMSD 曲线图 |

- 这是**所有下游结构分析使用的最终平衡轨迹**（后续 IE/RDF/密度图等均取末段窗口）。
- 论文中"最终 70 ns 生产 MD"，与二元项目 `Binary_Datas` 的 `*_md2`（70 ns）对应。

## 三、拓扑与力场

`modules/` 内为各组分拓扑：

| 文件 | 内容 |
|------|------|
| `PM6.itp` | 给体 PM6 力场参数 |
| `HDO.itp` | 受体1 HDO-4Cl 力场参数 |
| `BTn.itp` | 受体2 BTn 力场参数（各体系不同） |
| `DIO.itp` | 1,8-二碘辛烷添加剂 |
| `CF.itp` | 氯仿溶剂 |
| `complex.top` | 总拓扑（分子数：PM6 60 / HDO 168 / BTn 38 / DIO 94 / CF 50000） |

- 力场为 **GAFF（acpype 生成）+ RESP 电荷**（论文方法段）。
- 各体系仅 BTn.itp 因卤素位置不同而不同，其余共享。

`npt_1.sge` 模板结构（其余步骤类似）：


- 长循环任务（溶剂蒸发）用 while 循环串行跑完并逐步备份（`npt.gro_$loop`、`npt_1.gro_$loop`）。

## 五、可复现性与常见坑

1. **步骤目录即执行顺序**，新体系直接复制整套目录改 BTn 相关文件即可。
2. **2-npt 是 Berendsen，4-MD80/6-TA 是 Parrinello-Rahman**，论文参数表勿混。
3. **delete_solvent.py 会同步改 complex.top**，若手动删溶剂必须同步改拓扑，否则 grompp 报错。
4. **每循环备份结构**（`.gro_$loop`），便于失败回溯。
5. 与二元项目差异：二元用 GROMACS **2025.4**、cutoff **1.5 nm**、高压压实(100 bar)→常压→蒸发→80ns→去DIO→退火→70ns；三元用 2018.4、cutoff **1.0 nm**。跨项目比较时注意版本/参数差异。
