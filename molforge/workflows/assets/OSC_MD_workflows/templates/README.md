# templates/ —— 可复用脚本模板集

> 来源：`Ternary_Datas` 各工作流（见 `../00-总览与数据流转.md` 及各工作流文档）
> 用途：把三元体系沉淀的"MD+量化+速率"管线脚本整理为可复用模板，
> 复制到新体系后**只需替换参数**（分子/片段/窗口/口径），无需重写逻辑。

## 使用方法

1. **复制**：`templates/` 下把需要的子目录整目录复制到新体系项目；
2. **替换参数**：按 `../14-工作流复刻指南.md` 第三节"替换清单"逐项替换
   （分子、力场、拓扑分子数、片段原子区间、RDF 原子名、量化输入、对比变量）；
3. **核对菜单编号**：`run_igmh.sh` / `run_esp.sh` 中 Multiwfn 交互菜单编号以**你的 Multiwfn 版本**为准；
4. **核对 gmx energy 选项**：`run_ie.sh` 中能量分量选择号（LJ-SR/Disper-corr/Coul-SR/Coul-recip）以 `gmx energy` 实际列表为准；
5. **口径统一**：所有模板中的泛函/基组/溶剂/温度/窗口，若改一处须全流程一致，并写进论文方法段。

## 推荐工程化（见 14 文档第六节）

- 用 `params.yaml`（见同目录示例）集中管理分子数、片段区间、窗口、口径；
- 脚本优先读配置生成文件，避免到处改硬编码；
- 建立 `run_all.sh` 一键流水线；小文件进 git、大文件移动归档。
