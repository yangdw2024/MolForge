## 二、研究体系概述

本工作流针对 **PM6 : HDO-4Cl : BTx 三元有机太阳能电池（OSC）体系**开展多尺度计算化学研究，
目标是揭示第三组分 BTx 受体端基卤素（F/Cl）转位对 D/A 界面形貌与电荷转移动力学的调控机制
（学位论文：`Object_1\第三组分端基异卤转位对界面形貌的调控机制.docx`）。

### 2.1 分子组成

| 角色 | 分子 | 分子数 | 说明 |
|------|------|--------|------|
| 给体 D | **PM6**（PBDB-T-2Cl） | 60 | 共轭聚合物给体，四聚体 |
| 受体1 A1 | **HDO-4Cl** | 168 | 非富勒烯受体（四氯端基） |
| 受体2 A2 | **BT1~BT4** | 38 | 卤素转位异构体（F/Cl 位置不同） |
| 添加剂 | **DIO**（1,8-二碘辛烷） | 94 | 成膜溶剂添加剂 |
| 溶剂 | **CF**（氯仿） | 50000（逐步蒸发） | 成膜溶剂 |

> D+A = 60+168+38 = 266 个功能分子，与论文"266 个 D+A 分子"一致。

### 2.2 五个体系

| 体系编号 | 受体2 | 卤素模式 | 对应目录 |
|----------|-------|----------|----------|
| md0 | eC9（Y6） | 二元参比 | 无独立 MD 目录（参比数据在 `数据\RDF-yuan` 等） |
| md1 | BT1 | **FCLCLF** | `MD-1-BT1-FCLCLF` |
| md2 | BT2 | **CLFFCL** | `MD-2-BT2-CLFFCL` |
| md3 | BT3 | **FCLFCL** | `MD-3-BT3-FCLFCL` |
| md4 | BT4 | **FFCLCL** | `MD-4-BT4-FFCLCL` |

> 说明：md0 为不添加第三组分的二元参比（PM6:eC9），大部分分析目录保留 `md0` 数据用于对照。

## 三、总体数据流转（核心）

```
┌──────────────────────────────────────────────────────────────────────────┐
│  阶段1 分子建模与力场参数化                                                │
│   Gaussian 优化分子 → RESP 电荷 → GAFF 力场 .itp → Packmol 无定形盒 .pdb  │
└──────────────────────────────┬───────────────────────────────────────────┘
                               ▼
┌──────────────────────────────────────────────────────────────────────────┐
│  阶段2 GROMACS 分子动力学（每体系 7 步，见 01 文档）                        │
│   EM → NPT → 溶剂蒸发(循环删CF) → 80ns MD → DIO 处理 → 热退火 → 70ns 生产  │
└───────────────┬──────────────────────────────┬───────────────────────────┘
                │ 轨迹 .xtc / 结构 .gro          │ 轨迹（末段平衡区）
                ▼                               ▼
   ┌───────────────────────┐      ┌────────────────────────────┐
   │ 阶段3 构型提取（分子对）│      │ 阶段4 形貌分析              │
   │  D-A / A-A 分子对      │      │  RDF / 二面角-质心距 /      │
   │  .gro / .pdb / .gjf    │      │  二维密度 / 自由体积         │
   └──────────┬────────────┘      └────────────────────────────┘
              │
   ┌──────────┼──────────────┬──────────────────┐
   ▼          ▼              ▼                  ▼
┌────────┐ ┌────────┐  ┌────────────┐  ┌────────────────┐
│ 重组能  │ │ 电子耦合│  │ 偶极矩/ESP  │  │ IGMH 弱相互作用 │
│ Gaussian│ │Q-Chem  │  │ Multiwfn    │  │ Gaussian+Multiwfn│
│  λ     │ │ V_DA   │  │ μ / V_s     │  │ sign(λ2)ρ      │
└───┬────┘ └───┬────┘  └────────────┘  └────────────────┘
    │          │
    └────┬─────┘
         ▼
┌────────────────────────────┐
│ 阶段5 电荷转移动力学 K      │
│  k_CS / k_CR = f(λ, ΔG, V) │
└──────────────┬─────────────┘
               ▼
┌────────────────────────────┐
│ 阶段6 汇总与成稿            │
│  Excel/Origin 图表 → 论文  │
└────────────────────────────┘
```

### 数据流向说明

1. **MD 轨迹是几乎所有下游分析的公共数据源**（RDF、二面角-质心距、二维密度、自由体积、IE 均直接读轨迹/结构）。
2. **构型提取是量化计算的桥梁**：从平衡轨迹按 D-A 分子对提取二聚体构型，作为重组能（Gaussian）、电子耦合（Q-Chem）、偶极矩（Multiwfn）、IGMH（Multiwfn）的输入。
3. **量化结果汇聚到速率计算**：λ（重组能）＋ V_DA（电子耦合）＋ ΔG（前线轨道差）→ Marcus 速率 k_CS / k_CR。
4. **末端统一到论文图表**：所有数值经 Excel（.xlsx）汇总、Origin（.opju）成图、PPT/PICTURE 成稿。

## 六、文件命名规则

| 模式 | 含义 | 示例 |
|------|------|------|
