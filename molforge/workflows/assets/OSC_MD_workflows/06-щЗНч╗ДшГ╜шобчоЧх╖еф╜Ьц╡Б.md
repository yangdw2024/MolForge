# 06 · 重组能 λ 计算工作流（Gaussian 内球重组能）

> 数据目录：`chongzuneng\`（md0~md4 + pm6）
> 软件：Gaussian 16
> 方法：ωB97XD / 6-31G(d,p)，SMD=氯仿（部分）
> 输入：从 MD 轨迹提取的受体分子构型（`ply-{分子}-{帧}-{配对}.gjf`）

---

## 一、目的

计算受体分子（eC9 / HDO / BTn）的**电子转移内球重组能 λ**，作为 Marcus 速率（见 09 文档）的核心输入。

---

## 二、四步计算方案（4 点法）

对每个分子构型执行 4 个 Gaussian 任务：

| 任务标识 | 电荷/多重度 | 计算类型 | 物理量 |
|----------|-------------|----------|--------|
| `OPT01` | 0 1（中性单重态） | 几何优化 | E(N, R_N) |
| `OPT-12` | −1 2（阴离子二重态） | 几何优化 | E(A⁻, R_A⁻) |
| `OPT01-sp-12` | −1 2 | 单点（在中性优化结构上） | E(A⁻, R_N) |
| `OPT-12-sp01` | 0 1 | 单点（在阴离子优化结构上） | E(N, R_A⁻) |

### 重组能公式
```
λ = λ₁ + λ₂
λ₁ = E(N, R_A⁻) − E(A⁻, R_A⁻)     # 阴离子平衡结构上，中性−阴离子
λ₂ = E(A⁻, R_N) − E(N, R_N)       # 中性平衡结构上，阴离子−中性
```

> 说明：命名中 `sp01` = 电荷 0 多重度 1 的单点，`sp-12` = 电荷 −1 多重度 2 的单点；
> `OPT01` / `OPT-12` 分别对应中性/阴离子的几何优化 log。

---

## 三、输入文件结构（.gjf 示例）

```
%chk=ply-eC9-14-245.chk
%nprocshared=24
%mem=24GB
#p wb97xd/6-31g(d,p) sp SCF=conver=6

w

0 1
 C   90.420   80.010   49.180
 ...（坐标，从 MD 轨迹原样提取）
```

- `SCF=conver=6`：SCF 收敛阈值 10⁻⁶；
- 坐标范围大（~90–110 Å），为模拟盒原始坐标（未平移）；
- 计算资源：`%nprocshared=24`、`%mem=24GB`。

## 五、要点与坑

1. **λ 越小 → 电荷转移越快**：内球重组能主要来自分子几何弛豫（键长/键角变化），受体端基卤素位置改变会影响 λ；
2. **必须用同一泛函/基组做优化与单点**（本项目均 ωB97XD/6-31G(d,p)）；
3. **SMD 隐式溶剂**（氯仿）保持与 MD 环境一致；
4. 从 MD 提取的构型**原样进 Gaussian**（不重新优化坐标作为单点参考），λ 反映的是实际界面构型下的重组能；
5. 若只做电子转移（负离子态），注意电荷/自旋多重度正确（−1 2）；
6. 与二元项目一致：优化路由 `#p opt wB97XD/6-31g(d,p)`。
