# 05 · 组分间相互作用能 IE 工作流

> 数据目录：`IE\相互作用md0~md4\`
> 软件：GROMACS（trjconv + grompp + mdrun -rerun + energy）
> 方法：能量组分解 + 组分减除法
> 方法说明文档：`IE\gmx相互作用.docx`

---

## 一、目的

定量计算 D、A1、A2 三组分两两之间的**非键相互作用能**，分解为：
- **LJ-SR**（范德华/短程色散排斥）；
- **Coul-SR**（库仑短程）；
- **Coul-recip**（库仑倒空间/PME）；
- **Disper-corr**（色散校正）。

最终得到 E_els（静电）、E_dis（色散）等分量，用于解释 D/A/A 间的结合强度与形貌稳定性。

---

## 二、原理：组分减除法

对 A、B、C 三组分，分别构建 7 种拓扑，用**同一段轨迹**（rerun）重算势能：

| 拓扑 | 包含组分 | 得到 |
|------|----------|------|
| `A.top` | 仅 A | E(A) |
| `B.top` | 仅 B | E(B) |
| `C.top` | 仅 C | E(C) |
| `AB.top` | A+B | E(AB) |
| `AC.top` | A+C | E(AC) |
| `BC.top` | B+C | E(BC) |
| `complex.top` | A+B+C | 全体系 |

**相互作用能**（对各能量分量分别计算）：
```
E_int(A-B) = E(AB) − E(A) − E(B)
E_int(A-C) = E(AC) − E(A) − E(C)
E_int(B-C) = E(BC) − E(B) − E(C)
```
由于同一轨迹、同一力场，分子内贡献在相减中**精确抵消**，得到纯组间相互作用。

## 三、工作流步骤（以 md0 为例）

```bash
# 1) 用索引文件截取末段轨迹（65–70 ns，论文取最后 5 ns）
gmx_mpi trjconv -f ply-md3.part0004.xtc -s ply-md3.tpr -n indexABC.ndx \
                -o AB.xtc -b 65000 -e 70000
gmx_mpi trjconv -f ply-md3.part0004.gro -s ply-md3.tpr -n indexABC.ndx -o AB.gro

# 2) 用只含 AB 的拓扑重建 tpr
gmx_mpi grompp -f md.mdp -c AB.gro -p AB.top -o AB.tpr

# 3) rerun：在同一轨迹上重算 AB 子系统能量
gmx_mpi mdrun -s AB.tpr -rerun AB.xtc -e AB.edr

# 4) gmx energy 提取 4 项能量分量
gmx_mpi energy -f AB.edr -o LJ-SR.xvg       # 选 7
gmx_mpi energy -f AB.edr -o Disper-corr.xvg # 选 8
gmx_mpi energy -f AB.edr -o Coul-SR.xvg     # 选 9
gmx_mpi energy -f AB.edr -o Coul-recip.xvg  # 选 10

# 对 AC、BC、A、B、C 重复上述步骤
```

> 不同体系对应不同轨迹文件（md1→`ply-md7.part0007.xtc`、md2→`ply-md7.part0006.xtc`、
> md3/md4→`ply-md9.part0007/6.xtc`），并可额外取 60–65 ns、55–60 ns 窗口做时间收敛检验。

## 四、输出与汇总

每个子目录（A、B、C、AB、AC、BC）得到 4 个 `.xvg`：LJ-SR、Disper-corr、Coul-SR、Coul-recip。

汇总表（`.xlsx`）与 Origin 图（`.opju`）：

| 文件 | 内容 |
|------|------|
| `DA1-IE-6.opju` | 给体-受体1 相互作用能 |
| `DA2-IE-6.opju` | 给体-受体2 相互作用能 |
| `A1A2-IE-6.opju` | 受体1-受体2 相互作用能 |
| `IE-jiaozheng.opju` | 相互作用能校正（BSSE/周期校正） |
| `总IE.opju` | 总相互作用能 |
| `MD*.xlsx` | 各体系原始能量时间序列 |

## 五、结果解读要点

1. 有机给/受体整体电中性，**LJ（色散）通常占绝对主导**（>98%），库仑项相对小；
2. 组间库仑短程可正可负（局部电荷吸引/排斥抵消），`Coul-recip` 为 PME 倒空间项；
3. **注意**：PME reciprocal 项不按任意原子组拆分，`Coul-SR` 只是短程组间静电项，对中性分子组适合相对比较，不能称完整静电自由能；
4. **广延量必须归一化**（per-分子 / per-D-A-对 / per-接触原子），否则跨体系不可比（二元项目 HDO4Cl 分子数 174 vs 其余 190 即是一例）；
5. 若生产 mdp 未设 `energygrps`，原始 EDR 无分组能量，**必须走 rerun 路线**，不能直接 `gmx energy`。
