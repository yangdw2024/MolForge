# 03 · 二面角-质心距分析工作流（D/A 分子对堆积几何）

> 数据目录：`二面角-质心距\`
> 核心脚本：`analysis_mol.py`（numpy / scipy / sklearn）
> 输出：`results.xlsx`（每对分子 → 片段质心距 + 片段平面夹角）

---

## 一、目的

从平衡轨迹中统计**给体-受体（D-A）分子对**的：
- **片段质心距离**（dis，nm）→ 空间接近程度；
- **片段平面二面角**（angle，°）→ 分子堆积取向（face-on ≈ 90°，edge-on ≈ 0°/180°）；
- 距离-角度联合分布可揭示界面堆积构型与相分离形貌。

## 三、核心脚本 `analysis_mol.py` 逻辑

### 3.1 分子解析（parse_data）
- 读 `.gro`，按残基名识别 PM6（D）与 HDO/BTn（A）分子；
- 按分子（resid）分组，提取原子坐标、元素、原子序号。

### 3.2 片段定义
- **PM6（给体）**：4 个共轭重复单元片段（BDD/BDT 交替），每片段 ~38–40 原子；
- **HDO（受体）**：共轭骨架片段 + IC 端基片段。

### 3.3 平面拟合（fit_plane）
对每个片段的原子用三种方法拟合最佳平面，**取误差最小者**：

| 方法 | 原理 |
|------|------|
| 多元线性回归 | z = ax+by+c，法向量 (a,b,−1) |
| 非线性最小二乘 | scipy.optimize.leastsq 最小化点到平面距离 |
| SVD 奇异值分解 | 中心化后 SVD，最小奇异值对应法向量 |

误差评估：计算所有点到平面的平均距离与标准差，选平均距离最小的平面。

### 3.4 质心计算（calc_mcenter）
质量加权质心：`r_cm = Σ(m_i·r_i)/Σm_i`（原子量 C=12.01, S=32.06, H=1.01, O=16.00, F=19.00, N=14.01, Cl=35.45）。

### 3.5 全组合遍历
对"所有 PM6 分子 × 所有受体分子 × 所有片段对"计算：
- `dis = ||r_cm1 − r_cm2||`（nm）；
- `angle = arccos(|n1·n2|/(||n1||·||n2||))`（°）。

### 3.6 输出
- `results.xlsx`：列 = [Molecule1, Molecule2, M1Fragment, M2Fragment, distance, angle]；
- `data.csv`：中间解析数据。

## 四、应用方式

1. **距离截断筛分子对**：取质心距 < 阈值（如 1.0 nm）的分子对作为"接触对"，供后续量化计算（重组能/电子耦合/IGMH）选构型；
2. **角度分布统计**：统计 face-on / edge-on 比例，比较不同 BTn 体系对界面取向的影响；
3. **与 K 值关联**：接触距离与二面角 → 电子耦合 V_DA → 电荷转移动力学（见 08/09 文档）；
4. **论文图表**：距离-角度散点/等高图（论文 SI）。

## 六、常见坑

1. **片段定义须与拓扑残基一致**：不同受体（HDO/BTn）原子区间不同，换体系必须改片段原子区间；
2. **平面拟合取三种方法最小误差**，不要只用一个方法（扭曲片段 SVD 更稳）；
3. **质心距 ≠ 最近原子接触距离**：质心距反映整体靠近程度，接触细节用 RDF/IGMH 佐证；
4. 与二元项目 `Contact_Output03`（VMD 提取 D-A 二聚体 PDB）互为补充：二面角-质心距给出数值统计，VMD 给出具体构型。
