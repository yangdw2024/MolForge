> 软件：Gaussian 16（单点/TD-DFT）+ Multiwfn 3.8（表面分析）

## 一、分子表面静电势 ESP

### 目录
`数据\ESP\`：`BTP-4Cl.txt`、`CLF.txt`、`FCL.txt`、`FCLFCL.txt`、`FFCLCL.txt`、`HDO.txt`

### 方法
1. Gaussian 单点能（生成波函数）；
2. Multiwfn **主功能 12（定量分子表面分析）**；
3. 输出逐原子表面静电势统计：**全/正/负区域平均与方差**（kcal/mol）。

### 解读
- **V_s,max（正电势区）与 V_s,min（负电势区）的互补性**决定分子间静电识别与堆积取向；
- 受体端基 F/Cl 转位改变端基附近的 ESP 分布 → 影响与给体 BDT/BDD 的静电互补；
- 原子级 ESP 表（每原子 All/Positive/Negative 平均与方差）用于定位正负电势位点。

## 二、紫外-可见吸收光谱 UV-Vis（TD-DFT）

### 目录
`数据\uv-vis\`：`ec9.txt`、`hdo.txt`、`clf.txt`、`fcl.txt`、`fclfcl.txt`、`clclff.txt`、`工作簿1.xlsx`

### 方法
- Gaussian **TD-DFT**：`#p wb97xd/6-31g(d,p) td(nstates=20) scrf(smd,solvent=chloroform)`；
- 输出：各激发态能量、波长、振子强度、主要轨道跃迁贡献。

### 解读
- 吸收光谱范围与消光系数决定器件光捕获能力；
- HOMO-LUMO 能隙（可由吸收边估算）决定吸收边；
- 比较 eC9/HDO/BTn 与实验吸收光谱验证计算合理性。

## 三、单分子光物理速率（kr / kIC / kISC）

### 文件
根目录 `krkic.xlsx`（Sheet2: kr/kIC/kISC；Sheet1: ES1 与振子强度换算；Sheet4: 汇总）

### 方法
基于 S1 激发能 ES1 与振子强度 f 计算：
```
kr ∝ f · (ES1)²          # 自发辐射（Einstein A）
kIC = 非辐射内转换速率
kISC = 系间窜越速率（S1→T1）
```

### 结果示例（Sheet4）
| 分子 | ES1 (eV) | kr (s⁻¹) | kIC (s⁻¹) |
|------|----------|-----------|-----------|
| HDO-4Cl | 1.805 | 2.61e8 | 1.84e5 |
| BTP-2Cl2Cl | 1.686 | 2.37e8 | 9.03e5 |
| BTP-FClClF | 1.687 | 2.30e8 | 7.11e5 |
| ... | ... | ... | ... |

### 解读
- kr 大 → 荧光强；kIC/kISC 大 → 非辐射损失多；
- 与 Marcus 电荷分离速率（09 文档）共同决定激子命运（发光 vs 解离 vs 复合）。

## 五、要点与坑

1. **TD-DFT 用 ωB97XD + SMD 氯仿**（与 MD/其他量化一致），论文方法段勿写成 B3LYP；
2. ESP 的"全/正/负"三栏是逐原子统计，汇总时取极值点位 V_s,max/min；
3. kr/kIC 公式常数要写明单位换算（eV→cm⁻¹，×8065.54），保证可复现；
4. 能级（HOMO/LUMO）、偶极矩、吸收三项常并列在"单体表征"表中作材料基本面比较。
