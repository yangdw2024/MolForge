# MolForge 7.3.3 修复与模块审计报告（2026-11-03）

## 结论
本轮实际修改源码、补齐所请求的建模交互，并全面检查导入/菜单/79项注册入口；不能宣称所有科研模块已完全实现或原生双屏UI已目视通过。

## 用户截图对应改动
1. 编号：去掉3D黑底方块和2D青色块，改为细描边小字/轻量角标；3D默认仅重原子与选中原子，保留全部/仅选中范围，标签避让和稳定ID不变。
2. 2D：字体、背景留白、键端留白、双/三键间距、线宽和编号随缩放，不再缩短键却维持大字号；选中提示适度缩放。显示变化不改化学坐标。
3. 右键元素：2D/3D均有紧凑完整118周期表；3D自带实现，修掉以前委托主窗口不存在方法而无效的入口。检查器编号统一AtomId+1。
4. 自定义片段：选区保存、结构文件导入、JSON库和事务插入；支持独立追加/接枝、入口、元素/电荷/芳香性/键/坐标、一键撤销与稳定重做。文件解析在后台，当前分子改变则拒绝迟到插入。
5. 选择/冻结：单原子、连通片段、切键一侧片段、冻结原子选择；冻结约束接入命令预检、拖拽预览、MMFF/UFF/弹簧回退和xTB，保存工程后保留。
6. 美化：选区透明度、实体色和任意彩色Gaussian柔光；RGBA与全局共享VTK Gaussian splat，保留工程/撤销，增加含编号的纯3D PNG导出。柔光不代表真实物理发光。
7. 表格：修白底浅字、路径裁切不可读、按钮过长和旧版本标题；可滚动/调整列宽/悬停完整路径。路径探测明确标为未实跑，探测哈希只读前64KB。

## 本轮发现的实质功能问题与处理
- 2D端口和infrastructure两个坏导入：修正相对路径/模块导入。
- Mol*在Qt应用创建后导入WebEngine失败：初始化前设置共享OpenGL上下文；浏览器使用应用D/E目录的隔离profile。
- 旧79项中多项共用描述符/几何或Hückel/Gasteiger模型，却按ADMET、Hirshfeld、ESP、重组能等标题呈现：修正能力判断，未有专项实现时不再返回伪科学数值；科学描述符新增严格价态检查。保留独立工作流供真实输入调用。
- Hückel/Slater轨道演示菜单改为明确的近似示意；不称真实波函数/DFT轨道。
- xTB在GUI线程同步执行、失败静默变成力场成功、未保留冻结点：改后台快照与版本核查，失败直接返回，输出校验原子数/顺序/有限值/收敛/固定点。真实复现本机6.7.1pre ANCopt固定点缺陷，采用官方建议L-BFGS并通过水样例。
- 旧测试曾要求无输入也输出ESP/UV/IR/轨迹数值；改为反例验证缺输入/未实现不输出正式结果。旧VTK测试断言过时私有_glyph_scene，改检真实glyph数组、半径、可见性与actor数量稳定。未删失败项来伪造全绿。
