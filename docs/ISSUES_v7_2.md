## P0 崩溃类（已修复）

### ✅ 1. Studio2DWindow 无 canvas3d 崩溃
- **现象**：`AttributeError: 'Studio2DWindow' object has no attribute 'canvas3d'`
- **原因**：`document_tabs.py` 的 `_set_active_tool` 直接访问 `self.canvas2d, self.canvas3d`，但 2D 窗口只有 canvas2d
- **修复**：用 `getattr` 安全访问

### ✅ 2. 标签页/MDI 切换时 QTabWidget 被删除
- **现象**：`wrapped C/C++ object of type QTabWidget has been deleted`
- **原因**：`setCentralWidget(area)` 时 Qt 自动把旧中心部件（tabs）deleteLater() 了
- **修复**：切换前先 `setParent(None)` 解绑，防止被 Qt 删除

### ✅ 3. 删除原子残留氢
- **现象**：隐式氢模式下删完骨架，切到显式氢模式氢又蹦出来了
- **原因**：`DeleteAtomCommand` 只删原子本身，没连带删相连的氢
- **修复**：删除原子时自动连带删除相连的所有氢原子，支持完美撤销

## P1 功能缺失类（待修复）

### 4. 新建标签页后右键菜单不生效、画不了分子
- **现象**：多开一个画布之后，右击新画布没有菜单，也画不了分子
- **原因**：新建标签页时，canvas 的事件绑定或 document 绑定有问题
- **位置**：`document_tabs.py` 的 `add_document_tab`

### 5. 恢复标签页功能失效
- **现象**：MDI 多窗口模式下点"恢复标签页"，切不回标签页模式
- **状态**：之前修过一次生命周期问题，可能还有其他问题

### 6. Studio 子系统没有导出功能
- **现象**：文件菜单里没有导出 SMILES/XYZ/MOL/图片的选项
- **需要加**：
  - 导出 SMILES 到剪贴板
  - 导出 XYZ 文件
  - 导出 MOL/SDF 文件
  - 导出 PNG 截图

### 7. 没有自动保存和关闭提示
- **现象**：忘记保存就关窗口，数据丢了
- **需要加**：
  - 关闭窗口时提示"是否保存"
  - 定时自动保存（每 5 分钟）
