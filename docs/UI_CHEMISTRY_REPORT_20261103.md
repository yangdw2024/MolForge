# MolForge 7.3.2 本轮交付报告（2026-11-03）

本轮针对用户三张截图及半径/技能诉求修改真实源码。未宣称所有历史科研模块已完成。

## 修改与原因
- 工具条由固定高度挤压改为自然文字宽度的滚动容器，滚动条仅在溢出时出现并计入高度；2D坐标变换同步表头高度。工作区标题与模式切换分行；侧栏可横纵滚动，长卡片标题可滚动；2D状态提示精简。
- 周期表最小600×420、双向滚动；镧系/锕系范围从主表排除，118元素一份，取消重复/叠放。半径信息可换行。
- 编号采用独立Qt透明鼠标穿透叠加层，使用真实VTK投影；文字底色、避让和引线，更新跟随相机。菜单到2D/3D和3D菜单到按钮状态同步；稳定AtomId+1不改成易漂移的行号。
- 从RDKit2026.09.1导出118参考半径，周期表/渲染同源；CPK基础倍率1，球棍0.25。新原子、拖拽生长、缺坐标补点、弹簧回退与接环桥键采用元素相关共价半径初值，双/三/芳香键收缩是有说明的经验近似。输入坐标/真实测量不因显示模式改变。理想环模板仍非精确优化几何。
- 真实执行/撤销/重做形成当前会话审计事件；历史打开时随命令刷新。导出SKILL.md和operations.json，不运行序列化代码；无原始起点/映射不冒充可重放宏。
- 新建E盘项目维护技能，包含历史实际修复中的工程/科学边界。未向C盘写全局技能。

## 实际验证
- feature_checks.json：23项PASS，含118唯一元素、两轴滚动、按钮自然宽度、24实际投影标签及文字像素、无标签矩形重叠、旋转跟随、隐藏氢、半径/成键/坐标、时间线导出、历史实时更新。
- regression.json：原7组脚本退出0。旧1.45Å统一键长断言修为独立C–N参考和1.47Å，未放宽拓扑/坐标不变量。
- unit.log：既有修复unittest6项PASS。
- interaction_checks.json：既有Qt交互19项PASS，包含批量删除撤销/跨标签保存/MDI/监听器等。
- 项目维护技能和本轮真实操作导出技能通过skill-creator quick_validate。
- 离屏画面已生成并查看；测试加载系统已有Arial/微软雅黑解决离屏字体方框，不安装字体。
