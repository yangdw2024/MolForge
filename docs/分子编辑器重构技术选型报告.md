# 🔬 分子编辑器重构技术选型报告

## 一、调研结论（2025-2026 主流方案）

### 参考项目：MoleditPy（最现代的开源方案）
- **GUI 框架**：PyQt6（QGraphicsView 架构）
- **化学计算**：RDKit + Open Babel
- **3D 渲染**：PyVista + pyvistaqt
- **架构**：插件化、可扩展、支持脚本自动化

### 参考项目：rdEditor
- **GUI 框架**：PySide6
- **化学计算**：RDKit
- **特点**：纯 Python、面向对象、组件可复用

---

## 二、技术选型推荐

### ✅ 推荐方案：PyQt6 + RDKit + PyVista

| 层级 | 技术选型 | 理由 |
|------|---------|------|
| **GUI 框架** | PyQt6 | 现代化、QGraphicsView 天然适合分子编辑器、高 DPI 支持 |
| **化学引擎** | RDKit | 已在用、功能强大、Python 绑定成熟 |
| **3D 渲染** | PyVista + pyvistaqt | 不用自己写 OpenGL、性能好、Qt 集成方便 |
| **API 接口** | Python API + FastAPI | 既能本地调用，也能远程调用 |

### 为什么不用 Tkinter？
- ❌ 原生控件太丑，天花板低
- ❌ 没有 QGraphicsView 这样的专业画布
- ❌ 高 DPI 支持差
- ❌ 生态不如 Qt 成熟

## 四、API 接口设计（AI 可调用）

### Python API 示例
```python
from molecular_editor import EditorAPI

# 创建编辑器
editor = EditorAPI()

# AI 可以直接调用这些接口：
editor.new_document()                           # 新建文档
editor.draw_atom(x=100, y=200, element="C")    # 画原子
editor.draw_bond(atom1_id=1, atom2_id=2, order=2)  # 画双键
editor.import_smiles("CCO")                     # 从 SMILES 导入
editor.export_mol("output.mol")                 # 导出 MOL 文件
editor.optimize_geometry()                      # 几何优化
editor.calculate_properties()                    # 计算性质
editor.undo()                                   # 撤销
editor.redo()                                   # 重做
editor.select_all()                             # 全选
editor.delete_selection()                        # 删除选中
```

### HTTP API 示例（FastAPI）
```
POST /api/new               # 新建文档
POST /api/draw/atom         # 画原子
POST /api/draw/bond         # 画键
POST /api/import/smiles     # 从 SMILES 导入
POST /api/export/mol        # 导出 MOL
POST /api/undo              # 撤销
POST /api/redo              # 重做
GET  /api/molecule          # 获取当前分子结构
```

## 六、为什么选这个方案？

1. **现代化**：PyQt6 比 Tkinter 现代化太多，UI 质感直接上一个档次
2. **专业**：QGraphicsView 是专门为这种可视化编辑器设计的
3. **可扩展**：插件化架构，以后想加什么功能都方便
4. **AI 友好**：专门设计了 API 层，让 AI 模型可以直接指挥软件干活
5. **成熟**：RDKit + PyVista 都是成熟的工业级方案
