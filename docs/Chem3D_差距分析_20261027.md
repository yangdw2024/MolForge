## 二、MolForge 现有能力

### 已支持

| 功能 | 状态 |
|---|---|
| SMILES 读取 | ✅ |
| MOL/SDF 读取（RDKit） | ✅ |
| Gaussian log 读取 | ✅ |
| Gaussian gjf 导出 | ✅ |
| 2D SVG 导出 | ✅ |
| 2D PNG 导出 | ✅ |
| 3D vtkMoleculeMapper 渲染 | ✅ |
| PBR 材质 + IBL + SSAO | ✅ |
| 三点照明 | ✅ |
| 浅色系科学出版物风格 | ✅ |
| AIContext 工具集 | ✅ |
| Tool Registry（JSON Schema） | ✅ |
| 分子性质计算（MW/LogP/TPSA） | ✅ |
| 3D 构象生成（ETKDG + MMFF） | ✅ |
| MoleculeViewer 持久 Actor | ✅ |

### 不支持（和 Chem3D 的差距）

**格式支持（最大差距）：**
- ❌ PDB（蛋白质数据库）
- ❌ CIF（晶体结构）
- ❌ MOL2（SYBYL）
- ❌ MAE（Schrödinger）
- ❌ CDX（ChemDraw 原生）
- ❌ CML（化学标记语言）
- ❌ XYZ（通用坐标格式）
- ❌ 轨迹文件（XTC/DCD/TRR）
- ❌ 3D 动画导出（AVI/GIF）
- ❌ 矢量图导出（EMF/SVG 已有）

**功能差距：**
- ❌ 2D 交互式绘制（拖拽原子、画键）
- ❌ 3D 交互式选择（点选原子/键）
- ❌ 几何优化（接 Gaussian/MOPAC）
- ❌ 分子动力学轨迹播放
- ❌ 表面/等值面渲染（分子表面、轨道等值面）
- ❌ 多构象对比
- ❌ 批量处理
- ❌ 接 LLM API（现在只有工具骨架）

## 三、追赶优先级

### P0（先做，马上能用）

1. **XYZ 格式支持**（通用坐标格式，RDKit 原生支持）
2. **PDB 格式支持**（蛋白质/生物分子，RDKit 或 Biopython）
3. **CIF 格式支持**（晶体结构，gemmi 或 RDKit）
4. **MOL2 格式支持**（SYBYL，RDKit 支持）

### P1（然后做，提升竞争力）

5. **2D 交互式绘制**（拖拽原子、画键、改键型）
6. **3D 交互式选择**（点选原子、高亮）
7. **表面渲染**（分子表面、vdW 表面）
8. **轨迹文件支持**（XTC/DCD，MDAnalysis）

### P2（长期目标）

9. **几何优化集成**（接 Gaussian/MOPAC 后端）
10. **LLM API 接入**（DeepSeek/OpenAI/Ollama）
11. **轨道等值面渲染**（Cube 文件 → 等值面）
12. **批量处理**
13. **3D 动画导出**

## 四、碾压 Chem3D 的差异化优势

Chem3D 的弱点：
- 界面老（Windows 95 风格）
- 渲染质量差（简单 OpenGL，没有 PBR/IBL/SSAO）
- 不能接 LLM
- 闭源、贵
- 不支持现代 AI 工作流

MolForge 的差异化优势：
- ✅ **现代渲染**：PBR + HDR IBL + SSAO + 三点照明（Chem3D 没有）
- ✅ **AI-native**：LLM 当化学眼睛（Chem3D 做不到）
- ✅ **开源**：可扩展、可定制
- ✅ **Python 生态**：直接用 RDKit/MDAnalysis/Biopython
- ✅ **浅色系科学出版物风格**（Chem3D 是深色老风格）
