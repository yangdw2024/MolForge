## 二、技术栈（完整）

### 2.1 桌面外壳
- **GUI 框架**：PyQt6（外壳、工具栏、侧边栏）
- **3D 渲染容器**：QWebEngineView（内嵌浏览器，跑 Mol*）
- **2D 绘制画布**：QGraphicsView + QGraphicsScene
- **主题引擎**：QSS 样式表 + 自定义主题管理器

### 2.2 3D 渲染
- **渲染引擎**：Mol* Viewer（WebGL2 + PBR）
- **模型类型**：球棍/空间填充/棍/线框/表面/轨道
- **光照**：环境光 + 方向光 + 环境光遮蔽（AO）
- **抗锯齿**：MSAA 4x/8x

### 2.3 化学计算
- **主引擎**：RDKit 2025.3+
- **格式转换**：Open Babel（Pybel）
- **结构生成**：RDKit 2D 坐标生成 + ETKDG 3D 构象

### 2.4 AI 接口
- **Python API**：直接 import 调用
- **HTTP API**：FastAPI + Uvicorn
- **AI 框架**：LangChain / OpenAI SDK（预留）

### 2.5 数据存储
- **格式**：JSON（配置/数据库）+ MOL/SDF（分子）
- **路径**：`E:\YDW\Trae_Chemdraw\data\`

## 七、API 接口设计（AI 原生）

### 7.1 Python API 示例
```python
from molforge import Editor

editor = Editor()

# AI 可以直接调用这些接口：
editor.new_document()
editor.draw_atom(x=100, y=200, element="C")
editor.draw_bond(atom1_id=1, atom2_id=2, order=2)
editor.import_smiles("c1ccccc1")
editor.export_mol("output.mol")
editor.generate_3d()
editor.calculate_properties()
editor.undo()
editor.redo()
editor.select_all()
editor.delete_selection()
```

### 7.2 HTTP API 示例
```
POST /api/new               # 新建文档
POST /api/draw/atom         # 画原子
POST /api/draw/bond         # 画键
POST /api/import/smiles     # 从 SMILES 导入
POST /api/export/mol        # 导出 MOL
POST /api/generate3d        # 生成 3D
POST /api/undo              # 撤销
POST /api/redo              # 重做
GET  /api/molecule          # 获取当前分子
```
