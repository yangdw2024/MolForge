# MolForge v7.0 完整架构规划提示词

## 项目背景
MolForge 是一个自研分子建模工作台，目标是对标 GaussView / ChemDraw / Chem3D / VMD。
当前版本 v6.2，基于 PyQt6 + VTK 9.7.1，Python 3.13。

## 当前状态
- 主界面：三栏布局（左侧导航 + 中央工作区 + 右侧属性面板）
- 已实现：3D 点选/拖动、框选/套索、右键菜单、xtb 优化、构象搜索、HOMO/LUMO 轨道渲染
- Gemini 已写后端架构：欢迎界面 ShellFactory、三大 Shell、G:M:V 窗口管理器、Element Fragments 对话框、Gaussian Calculation Setup 对话框
- **但后端架构没有前端 UI 集成**，启动后直接进旧的三栏主界面

---

## 核心需求：完整的后处理分析模块

### Results 菜单（对标 GaussView）

#### 1. 波函数分析（Multiwfn 集成）
- **ESP 表面分析**：sigma2+/sigma2-/nu/Pi/MPI 描述符 + BWR 配色 ESP 表面图
- **HOMO/LUMO 能级图**：带分子轨道等值面图的能级骨架
- **OSC 能级图**：有机太阳能电池给体/受体能级对比
- **ELF 电子定域化函数**：电子定域化可视化
- **LOL 定域轨道定位器**：化学键可视化
- **Mayer 键级分析**：键级计算与可视化
- **Hirshfeld 电荷分析**：原子电荷分布
- **ADCH 电荷分析**：偶极矩改进电荷
- **NPA 电荷分析**：自然布居分析
- **电子空穴分析**：激发态电子空穴分布
- **IRI 相互作用区域指示**：弱相互作用可视化

#### 2. 分子性质计算
- **平面性分析**：二面角分布、RMSD 平面度
- **偶极矩计算**：分子偶极矩矢量可视化
- **分子体积与表面积**：SAS/SAV 计算
- **logP 预测**：辛醇水分配系数
- **pKa 预测**：酸碱常数
- **分子描述符**：MW、TPSA、HBA/HBD、Rotatable Bonds

#### 3. 分子间相互作用
- **能量分解分析（EDA）**：静电/交换/色散/诱导能
- **NCI 非共价相互作用**：RDG 等值面可视化
- **AIM 分子中的原子理论**：键临界点分析
- **氢键分析**：氢键网络可视化
- **π-π 堆积分析**：堆积距离、角度
- **范德华相互作用**：分子间距离分布

#### 4. 光谱分析
- **IR 红外光谱**：振动频率 + 强度 + 模式可视化
- **Raman 拉曼光谱**：拉曼活性计算
- **UV-Vis 紫外可见**：吸收光谱 + 跃迁归属
- **NMR 核磁共振**：化学位移预测
- **CD 圆二色谱**：手性分子光谱
- **ORD 旋光色散**：旋光度波长依赖

#### 5. 分子动力学（GROMACS 集成）
- **MD 模拟设置**：力场选择、盒子定义、溶剂化
- **轨迹可视化**：多帧渲染、平滑播放
- **RMSD 分析**：骨架偏差随时间变化
- **RMSF 分析**：残基涨落
- **回旋半径**：分子紧凑度
- **氢键分析**：氢键数量随时间变化
- **径向分布函数（RDF）**：分子间距离分布
- **二面角分析**：构象变化轨迹
- **能量分析**：势能/动能/总能量随时间
- **聚类分析**：构象聚类

## 架构需求

### 三大独立系统
1. **2D UI 系统**：完整的 2D 化学绘图系统（ChemDraw 风格）
2. **3D UI 系统**：GaussView G:M:V 多窗口系统（轻量级小窗口）
3. **2D-3D 分屏系统**：左右分屏，2D 编辑 + 3D 查看同步

### 欢迎界面
- 启动时显示欢迎界面
- 三个大按钮：2D 设计 / 3D 设计 / 2D-3D 分屏
- 点击进入对应的完整系统

### 3D UI 系统（GaussView 风格）
- 顶部菜单：File / Edit / Tools / Builder / View / Calculate / Results / Windows / Help
- 中央：VTK 画布
- 底部状态栏：原子数、电子数、电荷、自旋
- 底部按钮栏：Build / Select Placement
- 支持 G:M:V 多窗口并排
- 支持 1/2/4 视图布局切换
