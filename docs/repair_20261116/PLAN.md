# MolForge 7.4.2 全面修复执行规划

日期：2026-11-16

## 目标

以当前工作树（含上一轮未提交修复）为唯一基线，修复已知缺陷并建立可信验收证据。不得通过删除反例、放宽有效断言、伪造外部结果或将未测项目写成 PASS 来完成任务。

## 工作流

1. **基线取证**：盘点源码、测试、文档、Git 未提交状态、外部依赖和发布物；保存哈希。
2. **回滚保护**：备份 `molforge/`、`tests/`、`scripts/`、`docs/`、`.agents/`、构建与配置文件到 E 盘；重要文件修改前保留原副本。
3. **可信门禁**：先修正门禁标签、测试执行计数、环境与版本报告，再以其验证后续修改。
4. **科学与数据**：自旋、平面性/点群、可旋转键口径、CRYST1/PBC、PDB 重复序号、保存回读。
5. **UI 与交互**：22px/DPI、编号、2D/3D 绘制、选择、旋转、撤销、未保存保护、MCP 活动文档。
6. **大体系**：区分独立数据结构与主 GUI 路径；实测 32 万原子，不把理论数组内存外推为一亿原子 GUI 能力。
7. **外部与交付**：真实引擎按本机可用性逐项验收；凭据扫描；ZIP/wheel 隔离安装；同步镜像并重新构建。
8. **全量回归**：串行运行门禁、unittest、pytest、原生/离屏 GUI 和定向科学反例，保存日志与证据。
9. **闭环文档**：更新状态、操作记录、经验文档、剩余边界；只将有证据的项目标为通过。

## 范围

包含：当前已承诺的建模、2D/3D、科学信息、文件持久化、MCP、外部适配、测试与交付链路，以及审计和补充清单中的全部已知问题。

不伪造完成：79 个入口中的 Experimental 算法、需要不存在的外部数据/引擎/凭据的真实任务、一亿原子 60 FPS 等尚无主链路证据的能力。能修复实现或集成缺口的直接修复；缺少独立算法或外部条件的必须保留 Experimental/NOT_TESTED，并写明阻断原因。

## 验收原则

- 代码存在 ≠ 功能可用；单元测试 ≠ 真实桌面；mock ≠ 真实外部引擎。
- 每个 P0/P1 缺陷至少一个可复现反例和修复后断言。
- 性能测试串行、隔离、记录环境；解析耗时不冒充 GUI 帧率。
- 不删除用户文件；不永久删除测试产物；不修改科研原始数据。
- 不在 C 盘下载或安装任何内容。
