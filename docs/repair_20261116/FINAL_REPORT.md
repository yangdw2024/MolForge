# MolForge 7.4.2 全面分析与修复报告

日期：2026-11-16

## 1. 结论

本轮已完成项目工作流逆推、源码与测试审计、核心缺陷修复、真实桌面验收、外部计算引擎串行核验、干净环境安装、全量回归和交付包回读校验。

**当前状态是“核心已知缺陷已闭环的发布候选”，不是“所有 79 个科研入口和所有外部能力均已认证”。** 已通过的证据不再用 mock、离屏截图或样例解析冒充；缺少条件或实际失败的项目明确保留边界。

## 2. 核心修复

### 科学信息与几何

- 显式 multiplicity 优先，未知电子态标为“未指定（默认 Singlet/Doublet）”。
- 点群仅在存在外部引擎结果时显示；SVD 结果只作为线性/平面近似。
- 芳香碳、累积双键中心、显式三重态、独立环统计均有反例测试。
- 可旋转键明确标为“非环单键（自定义）”，不再等同 RDKit 严格描述符。

### 周期体系与工程持久化

- 支持正交/三斜晶胞、晶胞体积、分数坐标、CRYST1 和最小镜像。
- 距离、角度、二面角和 PDB 读写接入周期信息，VTK 显示晶胞线框。
- `.mforge` 回读覆盖 multiplicity、形式电荷、冻结状态、2D 坐标和晶胞。
- 修正空文档 `set_geometry(None)` 的工程回读问题。

### 原生桌面与 2D/3D

- 真实 Windows 桌面以 960×774、22px 中文界面验收，独立 QSettings 与 `MOLFORGE_DATA_DIR`。
- Ctrl+N、真实鼠标添加原子、拖拽建键、3D 旋转、Ctrl+S 和 Ctrl+O 均已执行。
- 保存工程为 843 字节，程序回读和原生重开均为 2 原子、1 键。
- 修复窄屏面板挤压、菜单截断、顶栏/状态栏截字、新标签未继承紧凑布局。
- 修复 0/1/2/≥3 原子相机；双原子视角避免沿键轴观察，并不再每次编辑重置用户视角。
- 保留大体系自定义颜色、半径、透明度；修复场景重复刷新与错误 LOD API。
- VTK 9.7 弃用的 `vtkTransformPolyDataFilter` 已替换为 `vtkTransformFilter`，最终 pytest 无警告。

### MCP 当前文档绑定

- 独立 MCP 服务不再固定读取咖啡因示例。
- 新增认证 localhost Qt TCP 服务和 stdio 转发。
- 真实外部 Python 进程已验证：读取 Desktop-A、添加氧原子、CommandBus 撤销、切换 Desktop-B。
- 测试生命周期改用 QApplication，避免 QCoreApplication 导致后续 QWidget 测试进程崩溃。

### 构建与安全

- 门禁要求真实非零退出码，并检查 unittest 实际执行数大于 0；失败立即终止打包。
- 平台信息来自真实系统，不再硬编码 Windows 11。
- `pyproject.toml` 显式打包顶层 `main.py`，修复 wheel 缺少控制台入口的问题。
- IGMH 默认资源改为 8 核/12GB，不再硬编码 24 核/24GB。
- 凭据扫描覆盖 366 个源码、测试和配置文件；仅发现明确测试假密钥，未发现生产凭据或私钥。
