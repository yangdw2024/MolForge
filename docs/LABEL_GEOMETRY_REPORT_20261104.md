# MolForge 7.3.4 标签与几何改进

3D 编号/符号改为 VTK 原生批量标签，和原子球共享相机、当前帧及多视口。元素构建器增加完整周期表、17 类理想几何、中心模板与可选显式壳层。已有结构支持局部几何整理和普通单键一侧扭转，全部通过 CommandBus 撤销/重做并保护冻结原子。

构象搜索在后台运行。浏览只预览，应用才修改文档；记录实际 MMFF94/UFF、优化收敛与 kcal/mol 能量。几何与力场均是模型初值/近似，不代替量子化学稳定性计算。

验收结果及边界见交付包 `verification/REPORT.md` 和 `verification/RESEARCH.md`。
