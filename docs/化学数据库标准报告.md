## 一、原子颜色（CPK 配色标准）

### 标准来源
**CPK 配色法**（Corey-Pauling-Koltun）：
- 由 Robert Corey、Linus Pauling 提出，Walter Koltun 改进
- 全球化学界统一标准，RCSB PDB、IUCr、所有分子可视化软件都用这个

### 完整 CPK 颜色表（行业标准值）

| 元素 | 符号 | 颜色 | RGB 值 | 色值 |
|------|------|------|--------|------|
| 氢 | H | 白色 | (255, 255, 255) | #FFFFFF |
| 碳 | C | 黑色/深灰 | (50, 50, 50) | #323232 |
| 氮 | N | 蓝色 | (50, 50, 255) | #3232FF |
| 氧 | O | 红色 | (255, 50, 50) | #FF3232 |
| 氟 | F | 绿色 | (0, 255, 0) | #00FF00 |
| 氯 | Cl | 绿色 | (0, 255, 0) | #00FF00 |
| 溴 | Br | 深棕红 | (150, 50, 0) | #963200 |
| 碘 | I | 深紫 | (100, 0, 100) | #640064 |
| 硫 | S | 黄色 | (255, 255, 0) | #FFFF00 |
| 磷 | P | 橙色 | (255, 150, 50) | #FF9632 |
| 硼 | B | 橙色 | (255, 180, 50) | #FFB432 |
| 硅 | Si | 浅绿 | (200, 200, 50) | #C8C832 |
| 金属 | 各种 | 各种灰色/绿色 | - | - |

### 权威依据
- RCSB PDB 官方文档：默认配体/离子用 CPK 配色
- IUCr（国际晶体学联合会）CIF 标准
- PyMOL、ChimeraX、Mol* 全部使用这个标准

## 二、原子半径数据库

### 两种半径
1. **共价半径**（Covalent Radius）：成键时用，用于球棍模型
2. **范德华半径**（van der Waals Radius）：空间填充模型（CPK）用

### 权威数据库来源

| 数据库 | 年份 | 权威性 | 说明 |
|--------|------|--------|------|
| **Pyykkö & Atsumi** | 2009 | ⭐⭐⭐⭐⭐ | 最新最全，单键/双键/三键都有 |
| **Cordero et al.** | 2008 | ⭐⭐⭐⭐⭐ | 基于晶体结构统计 |
| **IUCr 标准值** | 持续更新 | ⭐⭐⭐⭐⭐ | 晶体学国际标准 |
| **CRC Handbook** | 2025版 | ⭐⭐⭐⭐⭐ | 化学手册圣经 |

### 典型值（共价半径，单位 Å）

| 元素 | 单键 | 双键 | 三键 |
|------|------|------|------|
| H | 0.31 | - | - |
| C | 0.76 | 0.67 | 0.60 |
| N | 0.71 | 0.60 | 0.54 |
| O | 0.66 | 0.57 | 0.53 |
| F | 0.57 | - | - |
| S | 1.05 | 0.94 | - |
| Cl | 1.02 | - | - |
| Br | 1.20 | - | - |
| I | 1.39 | - | - |
| P | 1.07 | 0.94 | - |

## 三、键长标准值

### 计算方法
键长 = 原子A共价半径 + 原子B共价半径

### 典型键长（单位 Å）

| 键型 | 键长 | 说明 |
|------|------|------|
| C-C（单键） | 1.54 | 乙烷 |
| C=C（双键） | 1.34 | 乙烯 |
| C≡C（三键） | 1.20 | 乙炔 |
| C-N（单键） | 1.47 | - |
| C=N（亚胺） | 1.28 | - |
| C-O（单键） | 1.43 | 醇/醚 |

## 四、键角与分子构型（VSEPR 标准）

### VSEPR 理想键角（行业标准）

| 构型 | 键角 | 示例 |
|------|------|------|
| 直线形（Linear） | 180° | CO₂, BeCl₂ |
| 平面三角形（Trigonal Planar） | 120° | BF₃, NO₃⁻ |
| 弯曲形（Bent） | ~104.5° | H₂O |
| 三角锥形（Trigonal Pyramidal） | ~107.5° | NH₃ |
| 四面体形（Tetrahedral） | 109.5° | CH₄, 烷烃碳 |
| 三角双锥形（Trigonal Bipyramidal） | 90° / 120° | PCl₅ |
| 八面体形（Octahedral） | 90° | SF₆ |

### 杂化轨道标准角
- sp 杂化：180°
- sp² 杂化：120°
- sp³ 杂化：109.5°

## 六、我们的数据库设计

### 数据文件结构
```
data/
├── elements.json          # 元素周期表数据
│   ├── symbol            # 元素符号
│   ├── name              # 中文名
│   ├── atomic_number      # 原子序数
│   ├── cpk_color         # CPK 颜色 RGB
│   ├── covalent_radius   # 共价半径（单/双/三键）
│   ├── vdw_radius        # 范德华半径
│   ├── electronegativity # 电负性
│   ├── mass              # 原子量
│   └── valence           # 常见价态
│
├── bond_lengths.json     # 标准键长表
│
├── geometry.json         # VSEPR 构型/键角
│
└── templates/            # 常见分子模板
    ├── benzene.sdf      # 苯
    ├── thiophene.sdf    # 噻吩
    └── ...
```

### 数据来源权威性
| 数据类型 | 权威来源 |
|----------|---------|
| CPK 颜色 | RCSB PDB + PyMOL 默认值 |
| 共价半径 | Pyykkö & Atsumi 2009（最新） |
| 范德华半径 | Bondi 1964（行业标准，至今仍用） |
| 键长 | 基于共价半径计算 + 实验值校正 |
| 键角 | VSEPR 理论标准值 |
| 分子模板 | RDKit 内置模板 + 手动校准 |

## 七、和 GaussView 对比

| 维度 | GaussView 6 | 我们的方案 |
|------|-------------|-----------|
| 颜色标准 | CPK | CPK（完全一致） |
| 原子半径 | 内置 | Pyykkö 2009（更新更准） |
| 键长标准 | 内置 | 基于最新共价半径数据 |
| 键角 | VSEPR | VSEPR（完全一致） |
| 数据来源 | 不透明 | 全部公开，可追溯 |

## 八、结论

> 所有化学数据全部采用行业标准：
> - 颜色：CPK 配色（全球统一）
> - 半径：Pyykkö 2009 最新共价半径
> - 键长：基于共价半径计算
> - 键角：VSEPR 理论标准
> - 模板：RDKit 内置 + 手动校准
>
> **准确性和权威性完全不输 GaussView，甚至数据更新。**
